# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

VoltPulse takes data security, pipeline integrity, and credential safety seriously.

- **Private Disclosure**: If you discover a security issue (e.g. credential leakage risk, unsafe deserialization, or pipeline injection), please **do not open a public issue**.
- **Contact**: Please report the issue via GitHub's private vulnerability reporting feature on the repository.
- **Response Time**: We commit to acknowledging receipt of your report within 48 hours and providing a remediation plan within 5 business days.
