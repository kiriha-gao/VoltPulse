# 江苏合成电价情景：储能调度分析

这是 VoltPulse 的**合成数据演示报告入口**，不是交易中心历史结算数据报告。仓库曾保存过与价格样本不一致的回测汇总数字，因此本页不沿用旧结果。需要查看可复算的指标和收益时，请在当前代码与数据上重新生成报告：

```bash
python scripts/build_research_report.py --market jiangsu
```

脚本会按市场筛选价格，使用**同一份价格样本**重新计算价格指标与策略回测，并覆盖本文件。计算结果仅用于演示数据清洗、储能约束和简单策略与事后最优的差异；事后最优不能当作实际可执行收益。

公开真实数据的独立整理案例见 [广东周报数据说明](../../docs/public_data_case.md)。周度均价没有日内 96 点序列，不能用于此储能调度计算。改进过程与验证记录见 [PROGRESS.md](../../docs/PROGRESS.md)。
