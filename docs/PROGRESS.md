# VoltPulse 改进记录

这个文件记录每一轮真实完成的改进、验证方式和仍待解决的问题。Git 提交保留具体代码差异；本记录帮助读者理解为什么修改。

## 2026-09-26：确定求职版方向

**目标**：用一个可复现的小案例展示对电力市场的兴趣，以及发现问题、使用工具解决问题的过程。

**当前可核对的起点**：

- 仓库已有合成价格数据、数据质量检查、储能 MILP 和策略对比。
- 江苏、山东的 14 天价格序列是合成基准数据，不能据此得出真实省际市场收益结论。
- daily.yml 定时运行的是 fixture 模式；它展示自动构建流程，不代表每天采集真实市场价格。
- 事后已知全天电价的优化结果是理论对照，不能作为实际可执行收益承诺。

**接下来的改进顺序**：

1. 修正自动任务和展示措辞，让现有演示可信、可复现。
2. 获取一个来源清楚的公开价格样本，保留原始文件与来源信息；若没有完整数据，只报告实际可验证的分析。
3. 在同一参数口径下比较简单策略与事后最优，并记录一次具体的问题定位和修复过程。

每一步完成后再记录对应的运行证据。未完成的方向保留为计划，不写成已经实现的能力。
