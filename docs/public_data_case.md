# 一个真实公开数据案例：广东周度现货行情

## 为什么做这个案例

VoltPulse 原有江苏、山东价格曲线是合成算例。为了练习查找、整理和核对真实披露信息，这里单独使用广州电力交易中心的四期《南方区域电力现货市场每周行情一览》。保留每期原文链接，手工摘录其中**广东省发电侧日前、实时市场的周内日均成交加权均价**。

| 统计周 | 日前（元/兆瓦时） | 实时（元/兆瓦时） | 原始披露 |
| --- | ---: | ---: | --- |
| 2026-06-01 至 06-07 | 492 | 479 | [交易中心原文](https://www.gzpec.cn/news/scyj/202606/t20260612_36450.html) |
| 2026-06-08 至 06-14 | 428 | 396 | [交易中心原文](https://www.gzpec.cn/news/scyj/202606/t20260618_36478.html) |
| 2026-06-22 至 06-28 | 508 | 481 | [交易中心原文](https://www.gzpec.cn/news/scyj/202607/t20260701_36569.html) |
| 2026-06-29 至 07-05 | 368 | 407 | [交易中心原文](https://www.gzpec.cn/news/scyj/202607/t20260710_36622.html) |

来源页面均注明这些是**发电侧口径的快报数据，并非最终结算数据**。本案例没有找到 6 月 15—21 日的对应原文，因此没有补写该周，也不把四期数据称作连续一个月。

## 可重复核对的整理步骤

摘录表保存在 [CSV](../data/public/guangdong_weekly_2026_june.csv)，每行都带原文地址、摘录日期和 `is_simulated=false` 标签。运行：

```bash
python scripts/analyze_public_weekly.py
```

程序读取并核对来源域名、周起止日期和数值，输出四期周度加权均价的**简单平均**：日前 449.00、实时 440.75 元/兆瓦时；逐周日前减实时为 13、32、27、-39 元/兆瓦时。最后一期的方向与前三期不同，说明只看一个固定价差判断市场会遗漏变化。这些均值没有按成交电量再次加权，不是月度结算价。

## 能说明什么，不能说明什么

这个案例证明了从公开披露中找到原始出处、保留口径、检查缺周并复算简单指标的过程。周度汇总价没有日内 96 点曲线，**不能输入储能调度模型，也不能据此推算储能实际收益**。原有合成情景继续只用于验证模型与策略；未来若取得可核验的完整分时价格，再单独增加真实数据调度案例。
