# 双储能决策实验

这是 VoltPulse 的一个可操作作品：两家储能只根据各自观察到的收益，逐轮调整参与程度。页面用于探索“大家都想低买高卖时，会发生什么”，并提供可复算的参数与结果。

## 使用

```bash
python scripts/build_decision_lab.py
# 自定实验长度与随机种子
python scripts/build_decision_lab.py --rounds 240 --seed 23
```

打开 `public/decision-lab.html`，或从调度看板的“⑥ 双储能决策实验”进入。页面不依赖 CDN，保存后可以离线回放。`build_dashboard.py` 也会构建此页面。

切换 2 种合成价格情景、3 档收益更新速度、3 档价格反馈，共 18 组预计算实验；拖动回合进度、播放策略变化、查看当轮价格，并导出当前整组 CSV/JSON。页面中的数值由 Python 生成，浏览器不另算一套学习模型。

## 模型与口径

| 项目 | 设定 |
| --- | --- |
| 储能 A | 100 MW / 200 MWh，往返效率 85%，电芯吞吐损耗 30 元/MWh |
| 储能 B | 80 MW / 160 MWh，往返效率 90%，电芯吞吐损耗 45 元/MWh |
| 动作 | 观望、适中、积极，对应可行模板的 0%、50%、100% |
| 日内模板 | 11:00–15:00 充电、18:00–22:00 放电，达到 SOC 限值就停止；初末 SOC 50%，上限 90% |
| 收益更新速度 | α = 0.05、0.2、0.65 |
| 价格反馈 | κ = 0、1.5、4.0 (元/兆瓦时)/MW |
| 选择规则 | softmax，温度 0.2，初始动作价值均为 0 |
| 默认运行 | 120 轮，种子 17（B 的随机流使用 18） |

每轮先用已有价值抽取双方动作，再结算价格和收益，最后更新被选中的动作价值。动作价值更新为：`Q_new = Q_old + α × (本轮收益 / 50000 - Q_old)`。未选动作价值保持不变；参与者没有获取未选策略收益，也没有提前使用未来样本价格。更新速度描述新收益的权重，不代表真实参与者认知能力的测量结果。

模型价格为 `基础合成价格 + κ × (A净充电功率 + B净充电功率)`，净充电为正、净放电为负。双方共享这一价格，因此一方动作会影响另一方收益；关闭反馈时，这种相互影响消失，是一个对照情景。

净收益为 AC 侧售电收入减购电支出，再减双向电芯吞吐损耗。效率用往返效率的平方根分别计入充、放电过程。缩放同一个闭合模板可保持功率、SOC、充放互斥与初末电量平衡。

固定策略对照是在独立市场中双方始终选择“适中”，使用同一基础价格、设备参数和价格反馈系数。它不是“学习者与固定对手对战”，也不是理论最优或纳什均衡。

## 数据与边界

基础价格直接使用仓库中明确标注的 `shandong_sample.csv` 和 `jiangsu_sample.csv`，各 14 天、每日 96 点。默认 120 轮是这 14 个合成样本日按顺序循环重放，不是 120 天真实市场记录。构建产物包含源文件 SHA-256、来源标识和完整配置。

这是有限动作、固定时间模板、线性价格反馈下的仿真演示。反馈系数是情景参数，未经真实市场估计；没有网络约束、分段报价、市场出清、偏差结算或投资回报计算。单次随机轨迹不能证明真实行为规律、收敛性或某种规则普遍更优。

## 复现与验证

- `src/voltpulse/decision/game.py`：物理模板、价格反馈、收益和逐轮学习。
- `tests/test_decision_game.py`：SOC 闭合、功率限制、互斥、手算收益、对手影响、只更新已选动作、随机重放与未来信息边界。
- `reports/experiments/decision_lab.json`：默认实验的完整参数、样本、指纹与逐轮结果（构建生成）。
- `reports/experiments/decision_lab.md`：默认运行摘要（构建生成）。

可独立执行：`PYTHONPATH=src python -m unittest discover -s tests -p test_decision_game.py -v`。Windows PowerShell 先运行 `$env:PYTHONPATH='src'`，再执行上述 Python 命令。

下一次扩展可以围绕一个具体发现展开，例如增加多随机种子统计，或增加错峰调度动作；每次保留参数、结果和对应提交。
